# Nafas Maternal Watch

Create a professional, interactive clinical monitoring dashboard prototype called "NafasCare" for postpartum maternal monitoring.

Design it to resemble a realistic hospital patient-monitoring system, with a dark charcoal background, restrained medical green, cyan, white and amber colors, clear typography, and a clean 1440×900 desktop layout.

Include an EHG uterine electrical activity waveform labeled "Simulated EHG", maternal heart rate, blood pressure, oxygen saturation, manually entered estimated blood loss, sensor connection status, timestamp, and alert history.

Add three selectable demonstration scenarios: Stable, Clinical Review, and Urgent Review. Use fictional values that update consistently when each scenario is selected. Show contextual clinical review notifications, without presenting any scenario thresholds as medically validated.

Make the waveform animate smoothly. Add functional Play Demo, Pause, Reset, and scenario selection controls. Add a patient details panel and a clinical event log.

The interface must be polished, realistic, minimal, and suitable for a medical technology hackathon presentation. Avoid decorative gradients, excessive animations, generic AI dashboard styling, and unrealistic medical claims.

Clearly display "SIMULATION — NOT FOR CLINICAL USE". EHG must not be described as directly measuring blood loss or as a clinically validated diagnostic method for postpartum hemorrhage.

All controls must work in the preview. Use no real patient data.
